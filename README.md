
O tema escolhido para o projeto foi a banda Nirvana.

O site apresenta informações sobre a história da banda,
formação dos integrantes, principais álbuns e curiosidades sobre Kurt Cobain.

O objetivo foi criar um site moderno, responsivo e visualmente atrativo utilizando o framework Bootstrap 5.








O projeto foi dividido em múltiplas páginas HTML
interligadas através da navbar.

Estrutura:

• index.html → página inicial
• formacao.html → integrantes da banda
• morte.html → informações sobre Kurt Cobain
• sobre.html → informações adicionais
• style.css → estilização personalizada

O Bootstrap foi utilizado para facilitar a criação
de layouts responsivos e componentes visuais.

Os seguintes componentes Bootstrap foram utilizados:

• Navbar
→ menu de navegação responsivo

• Dropdown
→ submenu da seção História

• Carousel
→ exibição de imagens da banda

• Cards
→ apresentação dos álbuns

• Modal
→ curiosidades sobre a banda

• Grid System
→ organização responsiva do layout

• Buttons
→ botões de interação






Foi escolhido um visual inspirado na identidade visual
do Nirvana, utilizando principalmente as cores:

• Preto
• Amarelo
• Branco

As páginas foram organizadas com foco em:
• legibilidade
• responsividade
• simplicidade visual
• experiência do usuário

As imagens receberam bordas arredondadas e sombras para deixar o visual mais moderno.



O display flex foi utilizado em diversas partes do projeto, principalmente na organização dos cards de álbuns.

Classes Bootstrap utilizadas:
• d-flex
• justify-content-center
• align-items-center

O Flexbox ajudou a alinhar os elementos corretamente
em diferentes tamanhos de tela.





O site foi desenvolvido de forma responsiva utilizando
o sistema de grid do Bootstrap.

Foram utilizadas classes como:
• col-12
• col-md-6
• col-lg-4

Assim, o layout se adapta corretamente para:
• celulares
• tablets
• desktops



Durante o desenvolvimento do projeto, foram realizados ajustes de responsividade, estilização personalizada
com CSS e organização semântica do HTML5.

O Bootstrap facilitou bastante a criação de componentes modernos e responsivos, tornando o desenvolvimento mais rápido e organizado.









O projeto permitiu aplicar conhecimentos de HTML5,
CSS3 e Bootstrap 5 na criação de um site completo
e responsivo.

Além disso, foi possível compreender melhor a utilização de componentes prontos, organização de layout e boas práticas de desenvolvimento web.
